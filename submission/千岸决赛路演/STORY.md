# STORY.md — 千岸 QianAn 决赛路演（5 分钟）

## ① 用户意图对齐

**目标受众**：阿里「AI+跨境黑客松巅峰赛」决赛评委席——主办方（菜鸟智谷 / 阿里云 / 跨境百人会 / CSDN）+ 跨境行业专家。他们每天看几十个 AI Demo，对"套壳 Prompt 生成器"高度免疫，对"能自证、不自欺"的工程细节敏感。

**核心目标**：讲完 5 分钟，评委要相信三件事——
1. 痛点是真金白银的（1000–3300 元 / 3–7 天，不是编的）；
2. 千岸是**真 Agent**（会调研再决策、会调用工具、会跨任务记忆、会反思自愈），不是提示词包装；
3. 团队**有工程可信度**——连"什么情况下它做不到"都写清楚了，敢拿它上台。

**PPT 长度**：10 页（Hero 页配额 3 页 = 30%，落在 20–30% 区间）。

**视觉调性**：编辑级克制 / 精密工具感 / 橄榄墨绿 / 大留白 / 零 emoji。

**内容边界**：
- 必讲：痛点硬数字、90 秒五平台产出、四项 Agentic 能力的**运行时证据**、交付闸门"绝不假完成"、消融实验的量化贡献。
- 不讲：模型选型细节、Docker/部署链路、蜂群第 2–4 层（默认关闭，讲了是虚的）。
- 禁碰：把实测值说成普遍保证。"90 秒""合规零 error"必须带"已有测试样本下实测"限定语——这是本项目交付文档一贯口径，路演不得放宽。

## ② 页面布局骨架

**页面总数与分章**：10 页，不设目录页、不设章节扉页（5 分钟路演，目录是浪费的 30 秒）。全篇一条直线叙事：**问题的钱 → 我们的产出 → 凭什么做得到 → 凭什么值得信 → 现在就给你看 → 谁买单 → 哪里还不行 → 收束**。

| 段落 | 页码 | 作用 |
|---|---|---|
| 问题 | P1–P2 | 封面 + 痛点（钱与时间） |
| 方案 | P3 | 一次输入五份产出 |
| 证据 | P4–P6 | Agentic 能力 / 架构与闸门 / 消融实验 |
| 现场 | P7 | 演示动线（配合真机演示） |
| 商业 | P8–P9 | 谁付钱 + 诚实边界 |
| 收束 | P10 | 金句 + 落款 |

**Hero 页定位**：P1 封面（hero）、P3 方案（hero）、P10 收尾（hero）。三页互不相邻，各间隔 ≥1 个 supporting 页。

**rhythm 曲线**：P1 peak → P2 valley → P3 peak → P4 valley → P5 peak → P6 peak → P7 valley → P8 peak → P9 valley → P10 peak。无连续 ≥2 页 valley。

**非对称版式预算**：10 页中 8 页使用非对称版式（80%，≥40% 达标）。对称版式仅 2 页（P6 图表页、P10 收尾页），为该版式的全篇上限。

**版式重复约束**：`左大图+右侧文字`（P3）与 `非对称双栏`（P5、P8）合计 3 页 = 30%，未超 40% 上限。任意相邻两页版式不同。`N卡片横排` 全篇 0 次。
