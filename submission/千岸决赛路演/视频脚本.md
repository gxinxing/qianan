## 三、录屏段的实际内容

录制脚本：`/tmp/qianan_video/record.py`（playwright，1920×1080，注入演示光标 + 点击涟漪）

| 录屏动作 | 说明 |
| :--- | :--- |
| 打开首页 | 停留 5.5s，展示对话式工作台 |
| 光标移到输入框并点击 | 有涟漪反馈，观众能看到点击位置 |
| 逐字输入需求 | 60ms/字，模拟真实打字节奏 |
| 回车提交 | — |
| 生成过程 | 真实耗时（约 90–120s），页面轨迹持续滚动 → 后期 2× 加速 |
| 结果页滚动 | 鼠标滚轮上/下滚动，展示五平台产物卡片 |

**关键处理**：
- 生成段真实等待不剪掉——轨迹滚动本身就是"Agent 在工作"的证据，加速后约 27–60s。
- 录屏画面统一缩放到 1920×1080 输出（录制即为该分辨率，无需缩放）。
- 光标与涟漪是注入的 DOM 元素，不会遮挡正文；若最终成片觉得抢眼，可在剪辑时降低不透明度。

## 四、技术实现（实际采用的方案）

### 4.1 为什么没用 ffmpeg 的 subtitles 滤镜

本机 ffmpeg（9.0.1 / homebrew）**未编译 libass 与 libfreetype**，`subtitles` 与 `drawtext` 滤镜均不可用。因此改为：**用 PIL 把字幕渲染成透明图层，再用 overlay 合成**——overlay 是 ffmpeg 核心滤镜，必然可用。

踩坑记录：
- `subtitles=subs.srt:force_style='...'` → 样式串里的逗号被滤镜解析器当参数分隔符，报 `No option name near ...`
- 改用 ASS 文件 → `No such filter: 'subtitles'`（滤镜根本没编进去）
- `drawtext` 同样缺失

### 4.2 合成链路

```bash
# 1) PPT 页 → 静态片段（每页 6–15s，统一 1920x1080 / 30fps / yuv420p）
ffmpeg -y -loop 1 -i slides/s-01.png -t 6 -r 30 \
  -vf "scale=1920:1080,format=yuv420p" -c:v libx264 -preset medium -crf 20 -an seg/seg01.mp4

# 2) 录屏 → 三段（输入原速 / 生成 2.5x / 结果原速）
ffmpeg -y -i raw/session.webm -ss 0  -to 11  -vf "scale=1920:1080:flags=lanczos,fps=30,format=yuv420p" ... seg/screen_a.mp4
ffmpeg -y -i raw/session.webm -ss 11 -to 140 -vf "setpts=0.4*PTS,scale=1920:1080:flags=lanczos,fps=30,format=yuv420p" ... seg/screen_b.mp4
ffmpeg -y -i raw/session.webm -ss 140 -vf "scale=1920:1080:flags=lanczos,fps=30,format=yuv420p" ... seg/screen_c.mp4

# 3) 拼接（concat demuxer，各片段编码参数必须一致）
ffmpeg -y -f concat -safe 0 -i list.txt -c copy full.mp4

# 4) SRT → 透明字幕层（PIL 逐条渲染 PNG，含空白段，concat 成 qtrle/argb 视频）
python3 make_sublayer.py
ffmpeg -y -f concat -safe 0 -i sublayer/list.txt -fps_mode vfr -pix_fmt rgba -c:v qtrle sublayer.mov

# 5) 叠字幕 + 氛围音 → 成片
ffmpeg -y -i full.mp4 -i sublayer.mov -i bgm.wav -filter_complex \
  "[1:v]fps=30,format=rgba[sub];[0:v][sub]overlay=0:0:format=auto[v];[2:a]volume=0.35,atrim=0:180,afade=t=out:st=176:d=4[a]" \
  -map "[v]" -map "[a]" -c:v libx264 -preset medium -crf 19 -pix_fmt yuv420p \
  -c:a aac -b:a 128k -shortest "SimonStudio_千岸QianAn_演示视频.mp4"
```

**字幕样式**：苹方 SC（`PingFang.ttc` index 7 = SC Medium）38px，白色，半透明黑底圆角条，距底 58px。
**背景音乐**：ffmpeg 合成的 A 大三和弦 drone（220/277.2/329.6 Hz + 低通粉噪），无人声、无版权问题，音量压到 -28dB 左右。

### 4.3 录制脚本要点

- 1920×1080 视口，`record_video_dir` 录制，输出 25fps webm（后续转 30fps）
- **注入演示光标 + 点击涟漪**（`add_init_script` 注入 DOM），否则无声视频看不出操作位置
- 逐字输入用 `keyboard.type(delay=58)` 模拟真人节奏
- 生成阶段轮询页面文本（`合规通过` 计数）判断进度，超时按当前进度收尾

## 六、旁白稿（含语音合成）

**音色**：`zh-CN-YunxiNeural`（微软神经语音「云希」，男声）× 语速 `+4%`，经 `edge-tts` 合成。
**排片策略**：**以旁白为准反推画面时长** —— 先合成每段语音、量出真实时长，画面时长 = 语音时长 + 1.4s 留白（不低于各段下限）。这样音画天然同步，不需要硬对轴。

**字幕**：保留，内容为旁白文本按标点拆句（每句 ≤24 字），时间轴按句长比例分配在语音时长内 —— 即字幕与旁白逐句对齐。同时叠加极轻 BGM（音量 0.10），不抢人声。

**换音色**：改 `gen_voice.py` 里的 `VOICE` 即可（如 `zh-CN-XiaoxiaoNeural` 女声、`zh-CN-YunjianNeural` 沉稳男声），重跑 `gen_voice.py` + `build_video.py` 即可重出片。
