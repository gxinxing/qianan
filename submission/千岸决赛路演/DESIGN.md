# DESIGN.md — 千岸 QianAn 决赛路演

> 视觉依据：千岸已上线产品的设计语言（`qianan/web/app/globals.css` + `tailwind.config.js`）。
> 目标：让 PPT 和产品看起来是同一双手做的——暖白底、发丝边框、墨绿黑品牌色、等宽字眉题、编辑级留白。

| **底色 Base** | `#F7F7F5` | 全篇页面背景 |

| 角色 | Hex | 用途 |
| :--- | :--- | :--- |

### 2.1 色彩面积分配

> **修订（2026-09-15 晚，依据"重色太重、比例失调"的反馈）**：初稿在封面、收尾、P4/P8/P9 用了大面积深色块。现统一改为 **「重色只占小面积」**——深墨绿黑退居为文字与小标记，全篇不再有任何大面积深色背景。

| 色彩角色 | 全篇占比 | 用法约束 |
| :--- | :--- | :--- |
| **底色 Base** | 70–78% | 每页背景 |
| **白** | 8–14% | 卡片、图表底 |
| **辅色 Support** | 5–8% | 发丝边框、浅灰块（`#EFEFEB`） |
| **强调 Accent** | 4–8% | 眉题、焦点数字、勾选图标、关键描边、≤110×72 的焦点色块 |
| **主色 Main** | 3–6% | **仅文字与极小标记**；不得作为超过 120×80 的色块背景 |

- 深色填充块全篇总计 **≤ 2 处**，单块 ≤ 120×80px（当前仅 P5 架构图中「交付闸门」一格，106×72）。
- 需要"区块感" → 用 `#EFEFEB` 浅灰卡；需要"强调" → 用橄榄绿描边 / 短线 / 数字，不用深色填充。
- 每页的视觉锚点靠「大字号 + 大留白」制造，不靠色块堆重量。

**色彩节奏**：全篇以暖白为统一基调，节奏由「留白密度」和「强调色出现位置」制造，而非深浅底色切换（避免出现与全篇割裂的深色页）。

### 2.2 渐变与半透明

- **不再使用**深色页背景渐变（`linear-gradient(150deg, #20211E …)` 已全篇移除）。
- **柔光点缀**：左上/右上角 560–620px 径向柔光 `radial-gradient(circle, rgba(94,103,82,0.10~0.12) 0%, transparent 70%)`，用于 P1、P10，面积不计入强调色。
- **卡片投影**：`0 1px 2px rgba(26,32,39,0.05)`，极浅，不做浮夸立体感。
- **图片处理**：一律 `borderRadius: 10–14px` + `1px solid #DEDED9` 描边，不用蒙版压图。

### 2.3 通用禁忌

- 禁止全篇每页色彩比例雷同；禁止高饱和撞色；禁止使用色板外的彩色（尤其蓝、紫、橙、红——产品里没有这些）。

## 3. 字体系统

**字体家族（1 套主字体 + 1 组等宽签名）**
- 全篇统一：**苹方（`PingFang SC`）**，在 `Slide` 层通过 `fontFamily` 声明，全页继承生效（实测 10 页共 740 处 run 全部写入）。
  - 选型理由：macOS 系统原生 UI 字体，打开即所见即所得，不会因缺字体回退成陌生字形——这是"字体看着奇怪"的根治方案。
  - **弃用记录**：① 默认主题字体（Windows「等线」）→ macOS 缺字，回退宋体；② 阿里普惠体（`Alibaba PuHuiTi`）→ 本机渲染虽正常，但未安装该字体的机器会回退，且字形辨识度过强（被反馈"奇怪"）。两者均已弃用。
- **字重上限 700**：实测 800/900 会让中文回退到衬线字体（PingFang 家族无 800 字重，字体匹配失败后回退宋体），因此全篇最高只用 700。
- 等宽签名感（眉题 / 页码 / 数据标签 / 代码字段）：全大写 + 大 `letterSpacing` + 小字号实现。
  - **限制**：`letterSpacing` 只能用于宽度确定的容器。放在收缩包裹的容器（如 `alignItems: 'center'` 的父 Box）里时，末尾字符会被裁切（实测「SOURCE」渲染成「SOURC」），这类位置一律不用字距。

| 层级 | 字号 | 字重 | 行高 | 字距 | 用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| 封面主标题 | 72px | 700 | 1.08 | -1.5px | 仅 P1 |
| 收尾金句 | 56px | 700 | 1.25 | 0 | 仅 P10 |
| **巨型锚点数字** | **96px** | **700** | **1.0** | **-2px** | P2 的 `3–7` / `1000–3300` |
| 页面主标题 | 32px | 700 | 1.25 | -0.4px | A 区，全篇固定 |
| 卡片标题 | 17–21px | 600 | 1.4 | 0 | 卡片头 |
| 正文 | 13–14px | 400 | 1.6 | 0 | 段落、列表 |
| 数据标注 | 20px | 700 | 1.3 | 0 | 卡片内数字 |
| 眉题 / 页码 | 10.5–12px | 500 | 1.4 | +1.2~2.4px | 全大写，须置于固定宽度容器 |
| 限定语 / 注释 | 10.5–12px | 400 | 1.5 | 0 | `#858580` |

**关键规则**：巨型数字必须与正文形成 ≥6 倍字号跳跃；同一页内不得出现 3 种以上字号层级。

## 4. 信息密度门禁

| 页面类型 | 页数 | 正文字数 | 主视觉占 B 区面积 | 留白上限 |
| :--- | :--- | :--- | :--- | :--- |
| 封面（P1） | 1 | 约 90 | ≥ 40%（右侧产品图） | 45%（hero 豁免） |
| 内容页 · 单主题 | P2/P3/P5 | 190–230 | ≥ 30% | 35% |
| 内容页 · 列表/双栏 | P4/P8/P9 | 220–290 | 左色块 ≥ 30% | 35% |
| 数据图表页 | P6 | 190 | 图表 ≥ 45% | 35% |
| 截图演示页 | P7 | 200 | ≥ 50%（上方大图） | 35% |
| 收尾页（P10） | 1 | 约 70 | — | 45%（hero 豁免） |

- **容器填充率 ≥ 85%**：卡片内正文 + 尾部标注必须撑满卡片高度；尾部标注用 `marginTop: 'auto'` 钉底。
- **横向兄弟卡对齐**：同一行卡片的三段结构（标题 / 正文 / 尾部）在 y 轴上对齐，误差 ≤ 16px。
- **焦点留白**：巨型数字四周留 ≥ 40px 呼吸空间。
