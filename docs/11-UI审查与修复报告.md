## 五、待决策建议（P3 / 越权项）

### 5.1 【P1 系统性 · 需你拍板】ink 色阶重排（对比度 AA）

实测白底对比度：

```
ink-300 #b4bfce  1.86:1  ✗
ink-400 #97a6bb  2.47:1  ✗   ← .spec-label / 大量元信息
ink-500 #8090a8  3.24:1  ✗   ← 大量正文次级文字
ink-600 #65768d  4.64:1  ✓   ← 全站最浅的达标档
ink-700 #546175  6.28:1  ✓
```

暗色 hero（`#0e2033`）上的低透明度文字同样不达标：`brand-200/40` **2.92:1**、`brand-200/30` **2.21:1**、`brand-100/50` **4.36:1**。
状态徽标：`amber-600/amber-50` 3.07:1、`green-600/green-50` 3.15:1、`emerald-600/emerald-50` 3.58:1 —— 均低于小字 4.5:1。

**为什么没直接改**：把 400/500 抬到 4.5+ 会顶到 600，必须连带下压 600/700，**等价于重排整条色阶**＝改变全站视觉权重（品牌调性）。这落在「触及品牌调性 → 立即停下询问」的边界内，且单次改动预算（15 处）也已用满。

**建议方案（等你点头，一次改完）**：

```
ink-400  2.47 → 4.5    ink-500  3.24 → 5.4
ink-600  4.64 → 6.3    ink-700  6.28 → 7.6    （800/900 不动）
```

同时把暗色区 `brand-*/30~50` 提到 `brand-*/60` 以上，并给状态徽标换成 `-700` 档前景色。
**替代方案（改动更小、但只解决一半）**：只把 `.eyebrow` 也抬到 `ink-600`，其余不动 —— 我判断这会造成「同类元素一深一浅」的不一致，故未采用。

### 5.2 【需求层 · 越权】工作台缺图片上传

产品核心是「1 图 + 卖点 → 5 平台包」，但 `/workbench` 的表单只有名称/卖点/类目，没有图片入口（首页有）。若演示动线从工作台进，将丢失「以图改图、保持商品本体不变」这一差异化亮点。**建议你决定是否给工作台补图片上传**——这属于信息架构变更，我不动。

### 5.3 【P2 · 已保留原状】其他

- 「移除」按钮移动端热区 42×24px（< 44×44 建议值）。继续放大到 44px 高会覆盖缩略图 30%+ 并与「点图重选」抢点击，误触反而更要命 —— 我判断当前尺寸是更优解，**保留并上报**，由你定。
- 长任务无法中断（结果页生成中 / 自动上架执行中）：需后端提供取消语义，超出前端授权。
- `next.config.ts` 关闭了 TS/ESLint 构建校验：hackathon 速度优先的取舍可理解，但**类型错误不再在构建期暴露**。目前靠 `tsc --noEmit` 手工兜底，建议至少进 `Makefile` 的 CI 目标。
- 原生 `window.prompt`（差评原因）、`alert`（删除/反馈失败）：可读性差且不可样式化，建议换内联面板；本轮为控制改动量未动。
- `CompareSection` 的「差异」高亮：标题长度、描述长度几乎必不相等，导致琥珀高亮行接近全表，**高亮失去筛选意义**。建议改判据（如只在「主语言 / 属性数 / 合规结论」这类离散字段上判差异）。
