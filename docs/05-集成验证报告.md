### 2.3 已知问题与设计说明

| 项 | 严重度 | 说明 |
|------|--------|------|
| 云函数冷启动 | 🟡 体验 | 首次请求约 7-10s（实例拉起 + 依赖导入），热请求 0.15-0.3s；如需消除可配预置并发（控制台）|
| 任务存储为实例内存 + /tmp | 🟡 说明 | SCF 同步模式下生成结果随响应一次性返回；`/api/tasks/{id}` 由 `export.json` 落盘兜底还原 |
| `/api/trends` 无连接器 | ⚪ 按设计 | 未装趋势/竞品连接器时返回空并降级，不阻塞主流程 |

## 6. 部署与复现

```bash
# 一键部署（函数 + 环境变量 + 前端托管），见 cloudbase/deploy.sh
cd cloudbase && ./deploy.sh

# 手工等价步骤（tcb CLI 3.8.1，已实测验证）
cd cloudbase
tcb fn code update qianan-api --dir ../qianan/server/deploy_pkg --config-file /tmp/qianan-cloudbaserc.json
tcb config update fn qianan-api --all --config-file /tmp/qianan-cloudbaserc.json   # 含密钥的物化配置
tcb hosting deploy ../qianan/web/out -e ai-native-d5gfb0dm2a28d1fe9 --yes
```

> 注意：`qianan/server/deploy_pkg/` 与 `qianan/server/cloudfunctions/` 为构建产物（gitignore），由 `app/`、`data/`、`rules/` 同步生成；部署包内 vendored 依赖必须为 **linux cp310** 版本（macOS 版 .so 会导致云端初始化崩溃，详见 deploy.sh 内的同步逻辑）。
