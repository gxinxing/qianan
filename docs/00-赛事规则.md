# AI+跨境黑客松巅峰赛 — 赛事规则

> 来源：天池大赛页面 https://tianchi.aliyun.com/competition/entrance/532509
> 抓取时间：2025-08-25

## 一句话
三大跨境真实场景，用 AI 重解跨境真命题。命题来自跨境一线品牌大卖，由阿里云百炼平台提供算力支持。

## 主办 / 承办
- 指导单位：中国（杭州）跨境电子商务综合试验区
- 主办：菜鸟智谷、阿里云、跨境百人会、阿里国际人工智能人才孵化中心
- 赞助：湖州银行杭州分行
- 承办：CSDN
- 指定算力：**阿里云百炼平台**

## 三大赛道（三选一）
1. **AI 智能上新**：从选品到上架一键完成，AI 生成高转化主图/详情页，适配多平台规则，批量 Listing 与上架，新品上架从数天压到分钟级。
2. **AI 智能营销**：AI 批量生成 TikTok/IG/YouTube 短视频、Google/Meta 广告素材；智能匹配 KOL 并自动触达；多渠道智能投放/竞价/预算分配。
3. **AI 市场洞察**：AI 持续监控全球趋势、竞品价格与评论、供应链波动，转化为选品方向、定价策略。

## 奖金（总价值 16 万）
- 现金 10 万：一等 30000×1 / 二等 20000×2 / 三等 10000×3（开发组 6 队）
- 算力：初审前 100 队各得百炼 25000 Credits；复赛前 50 队再得 25000 Credits
- 认证：前 10 位获奖者免费获 AITIC-AI 智能体工程师认证（价值 3000 元）

## 参赛要求
- 独立开发者 / 技术团队 / AI 爱好者 / 高校学生 / 跨境电商从业者 / ISV 企业团队
- 1–5 人自由组队，不限地域平台，单人可报后补组队

## 时间节点
| 阶段 | 时间 | 交付物 |
|---|---|---|
| 报名组队 | 即日起 – 8.27 | 报名、组队、确定业务问题 |
| **创意初赛** | **提交 8.27 截止**；评审 8.31 | 方案名称 / 方案概述 / 核心功能 / 技术方案 / 选填附件 |
| 开发复赛 | 9.1 – 9.13 | 可运行 Demo + 代码仓库 + 演示视频 + 技术说明 + 体验方式 |
| 决赛路演 | 9.25 | 路演 PPT + 现场演示答辩 |

## 初赛评审标准（官方群公告）
- **不需要做出产品**，提交解决方案创意即可
- 重点评估：**业务价值 / 创新性 / 可行性 / 技术思路**
- 把精力放在：
  1. 明确要解决哪个场景中的具体业务问题
  2. 设计产品功能和技术方案路线
  3. 说明 AI 能力如何落地到跨境场景中

## 初赛填写项
1. **基本信息**：团队名称、队长信息、参赛场景
2. **方案名称**：给作品起个名字
3. **方案概述**：解决的问题、目标用户与业务痛点、3-5 项核心功能、方案亮点及预期效果
4. **技术方案**：拟使用的模型或能力、AI Agent 或工作流、数据处理方式、前后端及其他技术组件
5. **附加材料（选填）**：产品原型、流程图、架构图、演示视频、测试截图；已有代码可填仓库地址
