# 演示视频脚本（3 分钟）

> 商品：便携榨汁杯 380ml | 30 秒生成 5 平台上架包

---

## 场景 1：问题引入（0:00 – 0:30）

**画面**：快切模拟卖家桌面——Amazon 卖家中心、Shopee 后台、速卖通铺货页面、 Lazada 商品管理、TikTok Shop 商品卡各自蹦出，杂乱堆叠。

**旁白**：
> "一个新品铺 5 个平台，要配 5 套文案、5 套主图、5 套详情。A+ 全套外包 1000 到 3300，等 3 到 7 天。字符限制不一样，禁词表不一样，图片规范也不一样。"

**画面**：数字跳动——`× 5 平台 = × 5 倍成本 × 5 倍时间`。

**旁白**：
> "千岸——一稿多岸。一张白底图加一段卖点，30 秒出 5 套合规上架包。"

---

## 场景 2：核心演示（0:30 – 2:00）

**画面**：打开千岸 Demo（`localhost:3000` 或部署 URL）。

**旁白**：
> "先传一张白底商品图，再填一句卖点。"

**画面**（录屏实际操作）：
1. 拖拽「便携榨汁杯 380ml」白底图到上传区
2. 输入卖点：USB-C 快充，10 秒出汁，杯身可拆洗，仅 380g
3. 勾选 5 个平台全选
4. 点击「生成 5 平台上架包 →」

**画面**：进度条 / 流水线阶段 `plan → build → heal → reflect → evolve` 逐一亮起，约 15–25 秒。

**画面**：结果页弹出——5 个平台 Tab 并排：
- **Amazon**：标题≤200 字符埋 A10 词 + 5 点描述 + A+ 模块（品牌故事 / 卖点网格 / 规格对比）
- **Shopee**：泰语 + 印尼语本地化标题 + 主图合规标记（无水印 ✅ / 白底 ✅ / 800×800 ✅）
- **速卖通**：多语言标题 + 类目属性完整填充
- **Lazada**：东南亚多语适配
- **TikTok Shop**：商品卡文案 + 短视频脚本

**旁白**：
> "5 个平台的文案完全不一样——不是换皮，是各自按规则引擎重新生成。"

**画面**：切到「合规报告」标签——
38 项检查全通过，禁用词 0，字符范围 0 超限，图片规范 0 异常。
如果有 1–2 项 error，点开「自愈留痕」展示自动修订 + 复检通过的记录。

---

## 场景 3：差异化亮点（2:00 – 2:30）

**画面**：IDE 打开 `server/rules/amazon.json` — 展示结构化规则（标题 maxLength: 200, bannedWords 列表, aPlus 模块结构）。

**旁白**：
> "规则引擎不是大模型——是代码。每一条规则都是结构化 JSON，不可幻觉，不可绕过。"

**画面**：快速切 `compliance.py` 代码片段——PIL 四角白底采样示意。

**旁白**：
> "图片合规不是模型猜的——是 Pillow 实测四角像素值。文字规范是正则匹配。"

**画面**：展示以图改图流程——上传真实商品照 → 提示词锁定"保持本体" → 输出白底主图。

**旁白**：
> "视觉生成以图改图优先，保持商品本体 100% 一致。这是设计师审美 + AI 的结合。"

## 录制建议

| 项 | 建议 |
|---|---|
| 分辨率 | 1920×1080（至少） |
| 帧率 | 30fps |
| 工具 | macOS 自带 QuickTime 录屏，或 OBS |
| 旁白 | 预先写好稿，用 Audacity / 手机录音后对齐 |
| BGM | 无或极轻的背景电子乐（不盖旁白） |
| 时长控制 | 每个场景精确卡点，宁短勿超 3:10 |
