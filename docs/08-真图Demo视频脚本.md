# 千岸 QianAn · 3 分钟真图 Demo 视频脚本

> 目标：向评委证明「AI 智能上新」从占位图变成**真能生成合规主图**，并讲完「生成→自检→上架」闭环。
> 前置：后端 `QIANAN_MOCK=0`（真实百炼网关）、`/api/health` 返回 `mock:false`、前端 `:3000` 在线。
> 录制：Playwright 全屏录屏（Chrome 151，已软链就绪），导出 mp4；或 OBS 手动录屏照此脚本。

## 总时长分配
| 段 | 内容 | 时长 |
|----|------|------|
| 0:00–0:20 | 痛点开场 + 产品定位 | 20s |
| 0:20–0:50 | 一张白底图 + 中文卖点 → 提交生成 | 30s |
| 0:50–1:40 | 5 平台并行生成（进度条）→ 结果页真图展示 | 50s |
| 1:40–2:20 | 编辑文案 → 失焦即时合规校验（F1 演示） | 40s |
| 2:20–2:50 | 一键上架模拟卖家后台 → 截图留痕 live | 30s |
| 2:50–3:00 | 收尾：文件库 + 经营数据 + 进化提案 | 10s |

## 逐镜（Playwright 可脚本化）

**Shot 1 — 开场（首页 `/`）**
- 口播：「卖家上架 5 个平台，要写 5 套文案、做 5 张合规主图。千岸：一张图 + 一句话，约 90 秒交付。」
- 画面：首页 hero + 5 平台 logo 横排。

**Shot 2 — 提交（工作台 `/workbench` Stage 01）**
- 动作：填「便携 USB-C 榨汁杯」+ 卖点「便携充电 / 食品级 / 大容量」+ 勾选 5 平台 + 点「生成 N 平台上架包」。
- 强调：这是**真实商品照**上传（以图改图路径），非纯文生图。

**Shot 3 — 生成 + 真图（结果页 `/result/[taskId]`）**
- 动作：切到结果页，等流水线进度跑完；点 Amazon Tab。
- **关键帧**：主图区展示**真实生成的白底商品图**（非 Image Pending）——定格 3 秒，口播「这张主图是经多模态图像模型实时生成的，不是占位图」。
- 再切 Shopee / TikTok Shop Tab，展示各平台差异化主图与文案。

**Shot 4 — 人在回路（F1）**
- 动作：把标题改成长句（触发超长）→ 失焦 → 标题下立即出现红色 `title_length 超出长度上限` 角标，右侧合规报告同步变红。
- 口播：「生成不是终点。卖家改完当场知道合不合规，零额度消耗。」

**Shot 5 — 上架（发布面板）**
- 动作：点「一键上架」→ 切到 Playwright 驱动的模拟卖家后台录屏 → 展示 5 步留痕截图 → `status=live`、`listing_id=ML-xxxx`。

**Shot 6 — 收尾（文件库 `/files` + 后台 `/admin`）**
- 画面：文件库 24+ 包、后台指标卡（合规率/自愈/主图数）、Agent 进化提案列表。
- 口播：「生成、自检、上架、经营、进化——一条流水线。」
